# Binary Search

## Problem
Find the index of a target value in a sorted array. Return -1 if it is not present.

## Approach
Check the middle element. If it matches the target, return its index. If the target is larger, search the right half; otherwise, search the left half.

## Complexity
- **Time Complexity:** O(log n)
- **Space Complexity:** O(1)
