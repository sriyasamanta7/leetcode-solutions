# Longest Common Prefix

## Problem
Find the longest prefix shared by all the given strings.

## Approach
Compare characters of the first string with the corresponding characters of the other strings. Stop when a character differs.

## Complexity
- **Time Complexity:** O(n × m), where n is the number of strings and m is the length of the first string.
- **Space Complexity:** O(1).
