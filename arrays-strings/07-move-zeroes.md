# Move Zeroes

## Problem
Move all zeroes to the end of the array while maintaining the order of non-zero elements.

## Approach
Use a position pointer to track where the next non-zero element should go. Swap non-zero elements into the correct positions.

## Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
