
# Two Sum

- **Platform:** LeetCode
- **Difficulty:** Easy
- **Topic:** Arrays & Strings
- **Language:** C

## Problem
Given an array of integers and a target, find the indices of two numbers whose sum equals the target.

## Approach
Use two nested loops to check pairs of elements. If their sum equals the target, print their indices.

## Time Complexity
O(n²), because two nested loops are used.

## Space Complexity
O(1), because the program uses a fixed amount of extra space.
